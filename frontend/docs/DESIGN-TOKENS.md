# Design Tokens

Admin UI tokens are defined in `app/globals.css`.

| Token | Value | Usage |
|-------|-------|-------|
| `--primary` | `#0d9488` | Buttons, active nav, links |
| `--accent` | `#fff7ed` | Highlights |
| `--sidebar` | `#0f172a` | Sidebar background |
| `--sidebar-active` | `#0d9488` | Active nav item |
| `--sidebar-muted` | `#94a3b8` | Muted sidebar text |
| `--radius` | `0.625rem` | Border radius |

Typography uses the default Geist / system sans stack via Next.js.
